# Landing Page Tryout TKA SMA 2026

## Cara membuka
Buka file `index.html` melalui browser.

## Cara online
Upload seluruh isi folder ke hosting, cPanel, Netlify, Vercel, atau GitHub Pages.

## Menghubungkan formulir
Saat ini formulir menyimpan data secara lokal di browser untuk keperluan demonstrasi.

Buka `script.js`, lalu cari bagian:
`Hubungkan ke endpoint Anda di sini`

Masukkan URL webhook Google Apps Script, n8n, atau backend Anda pada fungsi `fetch`.

## Mengubah jumlah pendaftar
Di `index.html`, cari teks:
`187 siswa`

## Mengubah tanggal countdown
Di `script.js`, ubah:
`2026-07-15T23:59:59+07:00`
